Это проект на синтетических данных для примера. 

Файлы:
- contact_center_sql_examples.sql — SQL-запросы: GROUP BY, CASE WHEN, CTE, JOIN-подход, оконная функция и расчёт KPI.
- contact_center_python_analysis.py — анализ данных в pandas и визуализация.
- contact_center_excel_analysis.xlsx — исходные данные, KPI операторов/регионов, ежедневная динамика и графики.
